源流

自句读至国标

古人读书，以圈点断句，谓之句读：语绝处为句，未尽而顿处为读。千年之后，这套标记停顿的学问，写成了现代汉语的国家标准。

古 · 句读

文辞休止与停顿之处，古称句读。韩愈《师说》云：「句读之不知，惑之不解」——断句不明，则文义不通。

1920

教育部颁行《新式标点符号》，标点始有官定章法。

1951

中央人民政府出版总署公布《标点符号用法》，标点用法第一次有了全国统一的说明。

1990

国家语委、新闻出版署联合修订发布《标点符号用法》。

1995

升格为国家标准 GB/T 15834-1995。

2011 / 2012

GB/T 15834-2011 发布，2012 年 6 月 1 日实施，沿用至今——17 种标点的定义、形式、用法与书写位置，悉载于此。

❖

校法

三层递进

中文标点，日常写、日常读，绝大多数人不成问题。这个 Skill 服务两类人——想把标点学明白的，和工作中对文字较真、不能出错的。它像人校稿一样，从「看得出来」到「想得明白」，分三层做。

一曰

机械扫描

脚本先行，确定性规则一次性列全：半角标点混入中文、英文直引号、省略号写成三个句点、破折号写成两个连字符、引号括号不配对、概数误用顿号……保证不漏。

二曰

语义复核

脚本查不出的「用错了但形式合法」，由模型按判定矩阵逐条过：句末语气、顿逗分的层次、引号内外的句末点号、「说道」后的点号、书名号适用范围。

三曰

援引案例

每一处修改都落到国标条款号；凡是官媒公开讲过的类型，附上人民日报、新华社、央视等的原文案例与出处链接，明白「为什么错、为什么这样改」。

❖

三段式

报告的固定体式

每次检测的输出固定为三段，缺一不可。先看一例：八、九公里 这个写法，很多人一路用下来，从没觉得有问题。

其一 · 正确用法

问题清单：哪里错了，正确的应该是什么。

原文 八、九公里，应改为 八九公里。依据：GB/T 15834-2011 第 4.5.3.4 条。

其二 · 错在哪里

相邻数字连用表示概数时，是一个整体的数量概念，中间不应顿开。「八九公里」说的是大概的距离，并非「八公里」与「九公里」两项并列。

其三 · 官方案例

国标原文示例：「只能看到两侧八九公里和前方一二十公里范围内的地面。」人民日报微博《新版标点符号用法》同此。

报告末尾另附「修正全文」，可直接替换原稿；弹性用法（如并列引号之间的顿号）只作建议，不判错误。

❖

十八式

机械检查规则

十八条确定性规则，无依赖、可复现，同一文本无论何时检查结果一致。检出分三档：错误（明确违规）、警告（大概率该改）、待核（结合语境判断）。

第壹式

中文里混入半角逗号、句号、冒号等，改全角。

第贰式

英文直引号进中文，改中文弯引号。

第叁式

省略号写成三个英文句点或中文句号连写，改六连点。

第肆式

省略号连用不得超过两个。

第伍式

破折号写成连字符或全角减号，改两连「——」。

第陆式

重复标点只保留一个；可疑连用提示复核。

第柒式

问号、叹号叠用最多三个。

第捌式

引号前后必须配对。

第玖式

括号、书名号前后必须配对。

第拾式

数字间的顿号：概数应删，缩略并列可留。

拾壹式

并列引号、书名号之间通常不加顿号。

拾贰式

省略号不与「等」「等等」同时使用。

拾叁式

破折号后不接「即」「就是」，语义重复。

拾肆式

序次语后的点号：汉字数字用顿号，阿拉伯数字用下脚点，带括号不用点号。

拾伍式

汉字之间、汉字与标点之间不留多余空格。

拾陆式

省略号前后通常不加点号。

拾柒式

破折号之前通常不加点号。

拾捌式

数值范围用浪纹线，不用键盘上的波浪号。

佐证

官方案例库

案例库只收可核验的官方公开来源，每条注明媒体、篇名、日期与链接，严禁编造。无法核验的，一律不收录。

人民日报

微博《新版标点符号用法》系列（七项主要变化、占格与田字格书写规范）；海外版「杜老师语文信箱」专栏逐问逐答：引文末尾句号的位置、「某某说」后的点号、复句中的标点、破折号用法、引文中的括号。

新华社／中国记协

第二十四届中国新闻奖标点差错六例；第二十六届文字参评作品「标点符号差错」专章十四例（据原图逐条识读转录）；审核作品差错案例选编；2025 年海南初评案例。

《中国记者》

部署

一行装上

克隆仓库，跑安装脚本，即可装进 Codex、Claude Code、OpenCode、Trae、Kimi、TraeWork、WorkBuddy、ZCode。各平台读的是同一份规则；机械检查脚本只需 Node.js 18 以上，无需安装依赖。

# 克隆仓库
$ git clone https://github.com/mizzlelover/biaodian.git
$ cd biaodian

# 安装到全部支持的 AI 平台（macOS / Linux）
$ scripts/install.sh --all

# Windows
> .\scripts\install.ps1 -All
用法

把文稿交给它

安装后对 AI 说一句「检查这段文字的标点」，或直接运行：
node scripts/lint_punctuation.mjs --input ＜你的文稿＞

边界

只校标点，不动文字

不改文意、不改词语、不改数字、不改行文风格。GB/T 15834-2011 是推荐性国标，弹性用法只作建议。涉密文稿请勿上传在线模型。
