# 易混标点辨析（判定手册）

本文件是语义复核的操作手册。每条给出**一句话判别法**和**误/正对照**，例证来自国标与官媒（见 `official-cases.md`）。复核时按本文件逐条对号。

---

## 1. 逗号 / 顿号

**判别法**：并列的是"词语"用顿号；是"较长的短语、带语气词、或并列谓语"用逗号。

- 顿号（短）：我喜欢吃的水果有苹果、桃子、香蕉和菠萝。
- 逗号（长/带语气词）：我们需要了解全局和局部的统一，必然和偶然的统一，本质和现象的统一。
- 逗号（带语气词）：看游记最难弄清位置和方向，前啊，后啊，左啊，右啊，看了半天，还是不明白。
- 逗号（并列谓语）：他喜欢黄山的云海，喜欢九华山的佛光，喜欢天柱山的奇峰。

出处：人民日报《逗号、顿号、分号、点号等易混标点符号，如何正确使用？》。

## 2. 顿号 / 逗号 / 分号的层次

**判别法**：一句里同时出现三种停顿时，按"顿号＜逗号＜分号"由内到外排列。分句内部已用逗号，分句之间就用分号。

- 正例：有的学会烤烟，自己做挺讲究的纸烟和雪茄**；**有的学会蔬菜加工，做的番茄酱能吃到冬天**；**有的学会蔬菜腌渍、窖藏，使秋菜接上春菜。
- 正例：动物吃植物的方式多种多样**：**有的是把整个植物吃掉，如原生动物**；**有的是把植物的大部分吃掉，如鼠类**；**有的是吃掉植物的要害部位，如鸟类吃掉植物的嫩芽。

出处：人民日报/传媒茶话会《易混标点符号》。

## 3. 逗号 / 分号

**判别法**：分句短、语气紧、内部没有逗号 → 逗号；分句内部已有逗号、层次复杂 → 分号。

- 逗号：她拿起钥匙，开了箱上的锁，又开了首饰盒上的锁，往老地方放钱。
- 分号：纵比，即以一事物的各个发展阶段作比**；**横比，则以此事物与彼事物相比。

**注意**：用分号隔开的并列分句，**不能由逗号统领或总结**。
- 误：动物吃植物的方式多种多样，有的是……，如原生动物；有的是……，如鼠类；……
- 正：动物吃植物的方式多种多样**：**有的是……；有的是……；……

出处：人民日报《易混标点符号》。

## 4. "等/等等/什么的"前的点号

**判别法**：前面并列成分用**顿号** → "等"前**不加**任何点号；前面用**逗号** → "等"前**加逗号**。

- 正：现代生物学、物理学、化学、数学**等**基础科学的发展，带动了医学科学的进步。
- 正：写文章前要想好，主题是什么，用哪些材料，哪些详写，哪些略写，**等等**。
- 误：苹果、香蕉、**等**水果。

出处：国标 B.1.2；人民日报《易混标点符号》。

## 5. 冒号 / 逗号："说、道"之后

**判别法**：话语**在前**用冒号；话语**在后**、且处于句末用句号、后还有别的话用逗号；**插在话语中间**只能用逗号。

| 位置 | 点号 | 例 |
| --- | --- | --- |
| 引文之前 | 冒号 | 他说：“晚上就来家里吃饭吧。” |
| 插在中间 | 逗号 | “现在请皇上脱下衣服，”两个骗子说，“让我们为您换上新衣。” |
| 引文之后·句末 | 句号 | “我真的很期待。”他说。 |
| 引文之后·还有别的话 | 逗号 | “我有件事忘了说。”他说，表情有点为难。 |

- 误：'我最喜欢吃这家店里的牛肉面了。'老吴说，他每次回来都先去店里吃碗牛肉面。
- 正：“我最喜欢吃这家店里的牛肉面了。”老吴说。他每次回来都先去店里吃碗牛肉面。

出处：国标 B.1.5；人民日报海外版《“某某说”后的点号》。

## 6. 冒号：提示下文 / 总结上文

**判别法**：冒号后面是**下文的下属内容**（提示）或**对上文的概括**（总结）。

- 提示：他提出了三个要求**：**准时到、认真听、仔细记。
- 总结：证券交易所里穿红马甲的是经纪人，穿黄马甲的是管理人员**：**这是全世界统一的。
- 误（分说内部用分号总结）：……经纪人；黄马甲的是管理人员：这是全世界统一的。
- 总分复句的配合：总说后用冒号，分说内部并列分句之间用分号（见 `official-cases.md` C-SEMI-01）。

**禁忌**：一句之内不套用冒号；无停顿处不用冒号；转述（非直接引语）不用冒号。

出处：国标 4.7.3.1/4.7.3.2/4.7.3.5、A.6；人民日报《易混标点符号》。

## 7. 引号内外的句末点号

**判别法**：引文**完整独立**（或带问号/叹号）→ 句末点号放**引号内**；引文只是句子的**组成部分** → 句末点号放**引号外**。

- 正（独立，点号在内）：正如这位作家所言：“文学可以打通历史的幽闭之门……有情。”
- 正（作组成部分，点号在外）：正如这位作家所言，“文学可以打通历史的幽闭之门……有情”。
- 正（部分引用）：她说“明天见”就离开了。
- 正（独立，叹号在内）：同学们都说：“这次到农村参加的活动，让大家受益匪浅啊！”

**判别口诀**：看引语前是逗号还是冒号——逗号，多半是句子成分（点号在外）；冒号，多半独立成句（点号在内）。

出处：国标 B.2.1；人民日报海外版《引文末尾句号的位置》。

## 8. 括号：句内 / 句外 与内外点号

**判别法**：注释一个**词语** → 句内括号（紧跟该词语，末尾通常不用标点）；注释**整句/整段** → 句外括号（放在句末点号之后）。

- 句内：我校拥有特级教师（含已退休的）17 人。
- 句内：信纸上写着：“阿夷（姨），你好！”
- 句外：我忍不住喊道：“你，快点回来！”（我怎么用的是命令口气？大概是怕显出自己的胆怯吧。）
- 误：我们邀请了李老师（中文系副教授。）来做分享。（句内括号末尾不用标点）

**位置**：句内括号外是否用点号，取决于括号处是否停顿；句外括号末尾是否用句号，取决于括号内的语段结构。

出处：国标 A.8、B.2.2；人民日报海外版《引文中的括号》。

## 9. 破折号 / 括号（表解释说明时）

**判别法**：这个解释是**正文的一部分、可与前后连读、比较重要** → 破折号；只是**附带注释、可不连读** → 括号。

- 破折号：在今年——虎年，必须取得比去年更大的成绩。
- 括号：哈雷在牛顿思想的启发下，终于认出了他所关注的彗星（该星后人称为哈雷彗星）。

**破折号禁忌**：不再与"即/就是"连用；用破折号引出对话时不再给话语加引号。

出处：国标 B.1.7、4.10.3；人民日报《易混标点符号》。

## 10. 破折号 / 冒号（表提示或总结时）

**判别法**：要强调、有延展语气 → 破折号；常规提示下文或总结上文 → 冒号。

- 破折号：建议你们采取以下措施——
- 冒号：他提出三个要求：准时到、认真听、仔细记。

出处：国标 4.10.3.3、4.7.3。

## 11. 省略号 / "等"

**判别法**：**二者互斥**。能读出来用"等/等等/什么的"；读不出来的省略用省略号。

- 正：花园里有牡丹、月季、菊花…… 
- 正：花园里有牡丹、月季、菊花**等**花。
- 误：花园里有牡丹、月季、菊花**……等**花。

出处：国标 A.9.2。

## 12. 省略号 前 / 后 的点号

**判别法**：省略号前、后**通常都不用点号**。例外：前句语气强烈用了问号/叹号，或不用点号就无法标示停顿/结构关系；省略号后表强烈语气时可接问号/叹号。

- 误：他沉默了很久。……然后开口了。
- 正：他沉默了很久……然后开口了。
- 正（例外）：你到底想说什么？！……（强烈语气）

出处：国标 B.2.4。

## 13. 书名号 / 引号

**判别法**：是**作品名**（书、篇、刊、报、文件名、影视、音乐、诗歌、雕塑、软件）→ 书名号；是**活动、课程、课题、会议、奖项、商标、证照、机构名**或**主题、术语、别称、反语** → 引号或不用。

- 正：我读了《乡土中国》《月亮与六便士》三本书。
- 误：我读了《乡土中国》、《月亮与六便士》三本书。（并列书名号之间通常不加顿号）
- 误：“青年志愿者”活动写成《青年志愿者》活动。
- 正：《人民日报》刊登“乡村振兴”专题。（报纸名用书名号，专题名用引号）
- 层级：书名号内再用书名号，外双内单——《〈论语〉译注》。

**“题为……/以……为题”**：题是作品名 → 书名号；题是主题 → 引号。

出处：国标 4.15、A.13、B.1.8；人民日报微博《新版标点符号用法》。

## 14. 连接号的三种形式

**判别法**：看**连接的是什么**。

| 场景 | 形式 | 例 |
| --- | --- | --- |
| 化合物、表/图编号、号码、年月日、复合名词、型号、拼音外来语分合 | 短横线 `-`（占半字） | 3-戊酮、2011-02-15、010-88842603、吐鲁番-哈密盆地 |
| 时间、地域等**起止** | 一字线 `—`（占一字） | 沈括（1031—1095）、北京—上海特别快车 |
| **数值范围**起止 | 浪纹线 `～`（占一字） | 25～30g、第五～八课 |

- 误：北京-上海、2-3m、3~5人
- 正：北京—上海、2～3m、3～5人

**年月日简写**用短横线，不用顿号：正 2026-10-04；误 2026、10、04。

出处：国标 4.13、A.4.2；共产党员网《公文写作中这些标点，你用对了吗?》。

## 15. 间隔号

**判别法**：用于分界——外国人名内部、书名与篇名、词牌与题名、标题中并列词语、以月日为标志的事件节日的月日之间。

- 正：3·15 消费者权益日（阿拉伯数字，月日之间用间隔号）
- 正：一二·九运动（汉字数字，仅一、十一、十二月后用间隔号）
- 正：九一八事变（汉字数字，"九"后不用间隔号）
- 正：《沁园春·雪》

出处：国标 4.14；共产党员网。

## 16. 问号 / 句号：有疑问词不等于疑问句

**判别法**：句末**有没有疑问语气**决定用不用问号；句子里有"谁/什么/为什么/怎么"不代表是疑问句。

- 正（疑问）：这条路谁能走通？
- 正（陈述，用句号）：我不知道这条路谁能走通。
- 误：我不知道他为什么迟到？

出处：国标 A.2、4.2.3.1。

## 17. 选择问 / 连续问

**判别法**：**选择问**（A 还是 B）通常只在最后用一个问号；**连续问**（几个独立的问题）每个问号各用。

- 选择问：你周末是想去爬山，去看电影，还是在家看书？
- 连续问：他今天怎么没来？是生病了，还是有事？
- 误（把选择问写成连续问）：你周末想去爬山？去看电影？还是在家看书？

出处：国标 4.2.3.2；人民日报/教学材料。

## 18. 顿号 / 逗号：并列词语 vs 并列谓语

**判别法**：并列的**名词性词语**用顿号；并列的**谓语**用逗号。

- 顿号：黄山的奇松、怪石、云海、温泉，令游客流连忘返。
- 逗号：他喜欢黄山的云海，喜欢九华山的佛光，喜欢天柱山的奇峰。

出处：教学与编辑通行规范（国标 4.4.3、4.5.3.1）。

## 弹性用法清单（判"建议"，不判"错误"）

遇到以下情形，国标用的是"通常/宜/一般"，属于允许的选择，不要判错误：

1. 并列引号之间、并列书名号之间**用**了顿号（4.5.3.5 只说"通常不用"，中国新闻奖审核委员会亦认定不构成差错）。
2. 图表说明文字末尾是否完全不加标点（A.1 要求不加，但属编排惯例）。
3. 省略号前后偶用点号（B.2.4 有例外情形）。
4. 破折号前用点号（B.2.3"通常不用"，结构需要时可用）。
5. 文章标题末尾用问号、叹号或省略号（B.4 允许）。
