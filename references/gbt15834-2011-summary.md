## 二、标点符号的种类（第 3 章）

标点符号分**点号**和**标号**两大类，共 17 种。

- **点号**（作用：点断，表示停顿和语气）
  - 句末点号：句号、问号、叹号（表示句末停顿与句子语气）
  - 句内点号：逗号、顿号、分号、冒号（表示句内各种不同性质的停顿）
- **标号**（作用：标明，标示某些成分的特定性质和作用）
  - 引号、括号、破折号、省略号、着重号、连接号、间隔号、书名号、专名号、分隔号（10 种）

> 注：数学符号、货币符号、校勘符号、辞书符号、注音符号等特殊领域的专门符号，不属于标点符号（2.1 注）。

## 三、17 种标点的形式与基本用法（第 4 章）

| 编号 | 名称 | 形式 | 核心用法 | 条款 |
| --- | --- | --- | --- | --- |
| 1 | 句号 | 。 | 句末表陈述语气；也可表较缓和的祈使、感叹语气 | 4.1 |
| 2 | 问号 | ？ | 句末表疑问语气（含反问、设问）；选择问通常只在末项后用一个；可叠用（最多 3 个）；也可用于句内表存疑或不详 | 4.2 |
| 3 | 叹号 | ！ | 句末表感叹语气，也可表强烈祈使、反问；可用于拟声词后；可叠用（最多 3 个）；可在问号后再加（问号、叹号各一） | 4.3 |
| 4 | 逗号 | ， | 复句内分句之间一般用逗号；较长的主语/状语/宾语后、带语气词的并列成分之间、复指与插说成分前后等 | 4.4 |
| 5 | 顿号 | 、 | 并列词语之间；需停顿的重复词语之间；某些序次语后；概数之间通常不用；并列引号/书名号之间通常不用 | 4.5 |
| 6 | 分号 | ； | 复句内并列关系的分句之间（尤其分句内已有逗号时）；非并列多重复句第一层分句之间；分项列举各项之间 | 4.6 |
| 7 | 冒号 | ： | 总说/提示性词语后提示下文；总结上文；需说明的词语后表注释说明；书信讲话稿称呼语后。一句内一般不应套用冒号 | 4.7 |
| 8 | 引号 | “ ” ‘ ’ | 直接引用；着重论述或强调；特殊含义（别称、简称、反语）；引号内再用引号时**外双内单**；独立成段引文中段首只用前引号 | 4.8 |
| 9 | 括号 | （）〔〕【】[ ] | 圆括号：注释补充、订正补加、序次语、引语出处、拼音注音；方/六角括号：作者国籍或朝代、公文年份；方头括号：电讯开头、被注释词语。括号应尽量避免套用 | 4.9 |
| 10 | 破折号 | —— | 解释说明或补充说明；插入语；总结上文或提示下文；话题转换；声音延长；话语中断或间隔；引出对话；事项列举分承；副标题前；引文注文后标示作者出处 | 4.10 |
| 11 | 省略号 | ……（六连点） | 引文省略；列举或重复词语省略；语意未尽；说话断断续续；对话中沉默；特定成分虚缺。标示诗行段落省略时可连用两个（十二连点） | 4.11 |
| 12 | 着重号 | 下加小圆点 | 标示重要的文字、需要指明的文字。**统一为下加小圆点**；不得用下加直线或波浪线表示着重 | 4.12 |
| 13 | 连接号 | - – — ～ | 短横线（占半字）：化合物名称、表/图编号、号码与年月日、复合名词、产品型号、拼音外来语分合；一字线（占一字）：时间/地域起止；浪纹线：数值范围起止 | 4.13 |
| 14 | 间隔号 | · | 外国人名/少数民族人名内部分界；书名与篇章卷名分界；词牌曲牌诗体名与题名分界；标题栏目名称的并列词语之间；月日事件节日的月日之间 | 4.14 |
| 15 | 书名号 | 《》〈〉 | 书名卷名篇名刊物名报纸名文件名；影视音乐诗歌雕塑等作品名及简称；全中文或以中文为主体的软件名。书名号内再用书名号时**外双内单** | 4.15 |
| 16 | 专名号 | 下划直线 | 标示古籍、古籍引文或文史类著作中的专有名词。**现代汉语文本不应使用专名号** | 4.16 |
| 17 | 分隔号 | / | 诗歌接排时分隔诗行；标示音节节拍；分隔可选/可转换两项（或）；分隔成对两项（和）；分隔层级或类别 | 4.17 |

## 四、位置和书写形式（第 5 章，横排稿）

| 条款 | 要求 |
| --- | --- |
| 5.1.1 | 句号、逗号、顿号、分号、冒号置于文字之后，**占一个字位置，居左下，不出现在一行之首** |
| 5.1.2 | 问号、叹号占一个字位置，居左，不出现在一行之首。两个叠用占一个字，三个叠用占两个字，问号与叹号连用占一个字 |
| 5.1.3 | 引号、括号、书名号两端各占一个字位置；**前一半不出现在一行之末，后一半不出现在一行之首** |
| 5.1.4 | 破折号**占两个字位置**，上下居中，不能中间断开分处上行之末与下行之首 |
| 5.1.5 | 省略号占两个字位置；两个省略号连用时占四个字位置并**须单独占一行**；不能中间断开 |
| 5.1.6 | 短横线占半个字位置；一字线占一个字位置；浪纹线占一个字位置；连接号上下居中，不出现在一行之首 |
| 5.1.7 | 间隔号占半个字位置，上下居中，不出现在一行之首 |
| 5.1.8 | 着重号和专名号标在相应文字的下边 |
| 5.1.9 | 分隔号占半个字位置，不出现在一行之首或一行之末 |
| 5.1.10 | 标点排在一行末尾时，若为全角字符则占半角宽度（美观） |
| 5.1.11 | 为排版美观，可适当压缩标点占用空间 |

竖排稿（5.2）另有规定；电子文稿检测时一般不涉及，此处从略。

## 五、附录 A（规范性）："不能这样用"

这是检测时最实用的一条清单，逐条都对应一种高频错误。

| 条款 | 规则 | 典型违规 |
| --- | --- | --- |
| A.1 | 图、表的短语式说明文字，中间可用逗号，**末尾不用句号** | 图表标题末尾加句号 |
| A.2 | 用不用问号**取决于语气**，不取决于是否含疑问词；含疑问词但充当句子成分时，句末不用问号 | "我不知道他为什么迟到？" |
| A.3 | 顿号列举的较长并列成分，末项前用"以及（及）"时，"以及"前用逗号 | "以及"前用顿号 |
| A.4.1 | 含有顺序关系的并列各项之间用顿号，不用逗号 | 顺序关系并列项之间用逗号 |
| A.4.2 | 阿拉伯数字表示年月日的简写形式，用短横线连接号，不用顿号 | "2026、10、04" |
| A.5 | 分项列举各项中有一项已含句号时，各项末尾**不能再用分号** | 混用句号与分号分项 |
| A.6.1 | 表面像提示性话语、实际不是的，其后用逗号 | "他前思后想：还是算了。"（应为逗号或句号） |
| A.6.2 | 冒号提示范围应与提示性话语一致，避免过窄或过宽 | 冒号管不到该管的内容 |
| A.6.3 | 冒号应用在有停顿处，无停顿处不用冒号 | 无停顿处加冒号 |
| A.7 | "丛刊""文库""系列""书系"等选题名用引号；是选题名一部分则放引号内，反之放引号外 | 该地位未分辨 |
| A.8 | 句内括号紧跟被注释词语；句外括号位于所注释语段句末点号之后 | 两类括号位置互换 |
| A.9.1 | 省略号最多连用两个（12 连点）；须与连珠号区别 | 三个以上省略号连用 |
| A.9.2 | 省略号不能与"等""等等""什么的"同时使用 | "苹果、香蕉……等水果" |
| A.10 | 着重号统一为下加小圆点，不得用下加直线/波浪线 | 用波浪线表示着重 |
| A.11 | 浪纹线表数值范围时，不引起歧义可省略前数值的单位 | — |
| A.12 | 标题中已用间隔号隔开的并列短语，不应再用"和"类连词 | "《A·B》和《C》"式标题 |
| A.13.1 | 课程、课题、奖状、商标、证照、组织机构、会议、活动等名称**不用书名号** | "《青年志愿者》活动" |
| A.13.2 | 依指称意义判断：活动不用书名号，特定作品（如节目名）可用 | — |
| A.13.3 | 书名后表示所属类别的普通名词不标在书名号内 | "《红楼梦》小说" |
| A.13.4 | 括注属于书名则放书名号内，否则放外 | — |
| A.13.5 | 书名、篇名末尾的叹号或问号**放在书名号之内** | "《雷雨》！" |
| A.14 | 分隔号补充规则 | — |

## 六、附录 B（资料性）：易混辨析要点

- **B.1.1 逗号 vs 顿号**：都表停顿，逗号停顿长、顿号停顿短。并列词语间一般用顿号；并列词语较长或有语气词时可用逗号。
- **B.1.2 "等"前的点号**：并列成分用顿号时，"等/等等"前**不用**顿号或其他点号；并列成分用逗号时，"等"前**用**逗号。
- **B.1.3 逗号 vs 分号**：分句简短紧凑且内部无逗号，用逗号；分句内部已有逗号、层次复杂时，分句间用分号。
- **B.1.4 顿、逗、分的层次**：顿号层次最低 → 逗号居中 → 分号最高（可管第一层分句）。分句内已用逗号，则分句间用分号。用分号隔开的并列分句不由逗号"统领或总结"。
- **B.1.5 "说/道"后的点号**：引文前用冒号；引文后且处于句末用句号，后还有其他成分用逗号；插在话语中间只用逗号。
- **B.1.6 停顿长短排序**：句号＝问号＝叹号 ＞ 冒号（涵盖一句话时）＞ 分号 ＞ 逗号 ＞ 顿号。
- **B.1.7 破折号 vs 括号**：破折号表较重要的解释说明，是正文的一部分，可与前后文连读；括号表较一般的注释，非正文，可不连读。
- **B.1.8 "题为……""以……为题"**：题是作品名看作用书名号；是主题而非特定作品标题，用引号。
- **B.2.1 引号内外点号**：引文完整且独立，或虽不独立但带问号/叹号时，引号内句末点号保留；否则引号内不用句末点号。引文处于停顿处且引号内未用点号时，引号外用点号。
- **B.2.2 括号内外点号**：括号内末尾可用问号、叹号、省略号；句内括号末尾通常不用标点。句外括号末尾是否用句号由语段结构决定。句内括号外是否用点号，取决于括号所处位置是否为停顿处。
- **B.2.3 破折号前后**：之前通常不用点号（结构需要时可用）；之后通常不紧接其他点号（表语音停顿或延长时其后可接问号或叹号）。
- **B.2.4 省略号前后**：之前通常不用点号（强烈语气、或不用无法标示停顿/结构关系时例外）；之后通常也不用点号（强烈语气可在其后用问号或叹号）。
- **B.3 序次语后的标点**：①"第/其"字头及"首先/其次/最后"后用逗号；②不带括号的汉字数字或天干地支后用顿号；③不带括号的阿拉伯数字/拉丁字母/罗马数字后用下脚点（外文符号）；④加括号的序次语后**不用任何点号**；⑤阿拉伯数字与下脚点结合表示章节关系时末尾不用点号。
- **B.4 文章标题**：末尾通常不用标点符号，必要时可用问号、叹号或省略号。

## 七、检测可判定清单（速查）

形式层（可由 `scripts/lint_punctuation.mjs` 自动判定）：
半角/英文标点混入中文、英文直引号、省略号写法（`...`/`。。。`/单 `…`）、破折号写法（`--`/单个 `—` 的歧义）、重复与超量叠用标点、引号与括号配对、顿号疑用于概数、并列引号/书名号间的顿号、省略号与"等"同现、序次语后标点、汉字间多余空格、数值范围用 ASCII 波浪线。

语义层（必须由模型按第 4–6 节判定）：
句末语气与点号是否匹配、句内点号层次与停顿是否合理、引号内外句末点号位置、"说/道"后的点号、破折号与括号的分工、书名号适用范围、"等"前点号、冒号提示范围与是否套用。
