# 检测报告模板

`biaodian` 的输出**必须**是下面这个三段式结构：**问题清单 → 逐处说明与官方案例科普 → 修正全文**。案例只能取自 `official-cases.md`，不得编造。

---

## 报告骨架

```markdown
# 标点检测报告

- 检测对象：<文件名 / 段落位置>（约 N 字）
- 检测依据：GB/T 15834-2011《标点符号用法》
- 结论：共 N 处（错误 a 处，建议 b 处）。最要紧的是：<一句话>。

## 一、问题清单：哪里错了，正确的是什么

| # | 位置 | 原文 | 问题 | 应改为 | 依据 |
| --- | --- | --- | --- | --- | --- |
| 1 | 第X段 | …… | …… | …… | 4.x.x |
| … | | | | | |

> 图例：**错误**＝违反国标明文；**建议**＝国标为"通常/宜"，属弹性用法，供参考。

## 二、逐处说明与官方案例科普：为什么错、为什么这样改

### 1. <位置>：<原文片段> → <修改后>
- **为什么错**：用大白话讲清语气/停顿/结构上的差别。
- **正确用法**：一句话给出可操作规则。
- **官方案例**：<媒体>《<篇名>》（<日期>）原文：…… 
  出处：<链接>
- **依据**：GB/T 15834-2011 <条款号>

### 2. …（编号与第一部分一一对应）

## 三、修正全文

<把上面的修改全部落回原文，输出可直接替换的干净版本>

## 附：可商榷项（可选）

- 逐条列出属弹性用法、需要作者定夺的地方。
```

**硬性要求**

- 第一部分每一条，必须在第二部分有**同编号**的解释与案例。
- 每条修改都要有条款号；能配官方案例的必须配。
- 第二部分讲“为什么”时，优先引用国标示例与官媒原话。
- 报告只谈标点；错别字、语法、事实问题不写入主体。

## 完整范例

> 检测对象（示例稿）：
> `这次培训主要有三个目标,一是掌握标点符号的规范用法,二是熟悉公文格式。我们邀请了张老师（中文系副教授。）来做分享。他读了《乡土中国》、《月亮与六便士》两本书。飞机在6000米高空飞行时,只能看到两侧八、九公里范围内的地面。他想了很久...然后说"这个方案我不同意"。这就是答案--唯一正确的答案。1、请大家先读题。`

### # 标点检测报告

- 检测对象：示例稿（约 130 字）
- 检测依据：GB/T 15834-2011《标点符号用法》
- 结论：共 9 处（错误 6 处，建议 3 处）。最要紧的是：**“说”字后的引语没有用冒号，且句末点号放错了位置**——这会让人读不出这句话到底是谁说的、说到哪里结束。

#### 二、逐处说明与官方案例科普

**1. `,` → `，`（第1句两处、第4句一处）**
- **为什么错**：中文书面语用全角标点，逗号占一个字位置、居左下。半角逗号是英文标点，出现在中文句子里，排版上会显得局促，也不符合书写形式要求。
- **正确用法**：中文之间的逗号一律用全角 `，`；只有在纯英文片段或数字（如 1,000）中才用半角。
- **官方案例**：央视网《［每日新闻报］发信息少了标点符号 错理解意思闹笑话》（2018-10-30）——标点用法直接影响读者对句子的理解。
- **依据**：GB/T 15834-2011 5.1.1。

**2. `（中文系副教授。）` → `（中文系副教授）`**
- **为什么错**：这个括号是**句内括号**，只注释“张老师”这一个词语，是句子的一部分；括号里末尾的句号把注释变成了一个独立句子，位置就不对了。
- **正确用法**：注释词语的句内括号紧跟被注词语，末尾通常不加标点。（如果括号里是独立成句的完整句子，才保留末尾标点，且括号要移到句末点号之后。）
- **官方案例**：国标示例“我校拥有特级教师（含已退休的）17 人”——句内括号末尾没有标点；人民日报海外版《引文中的括号（杜老师语文信箱）》（2026-08-29）亦作同样解释。
- **依据**：GB/T 15834-2011 B.2.2、A.8。

**3. `《乡土中国》、《月亮与六便士》` → `《乡土中国》《月亮与六便士》`**
- **为什么错**：书名号本身已经把并列成分分隔清楚了，再加顿号是多余的。
- **正确用法**：并列的引号之间、并列的书名号之间**通常不用顿号**；只有当中间插入别的东西（如括注）时才用顿号。
- **官方案例**：国标示例“《红楼梦》《三国演义》《西游记》《水浒传》是我国长篇小说的四大名著”；中国新闻奖审核委员会亦认定，此处顿号属可用的弹性用法、不构成差错——所以本条列为**建议**。
- **依据**：GB/T 15834-2011 4.5.3.5。

**4. `,` → `，`（第4句）**：同第 1 条。

**5. `八、九公里` → `八九公里`**
- **为什么错**：相邻数字连用表示**概数**时，是一个整体的数量概念，中间不应顿开。
- **正确用法**：概数之间不用顿号。只有相邻数字连用表示**缩略并列**时才用顿号（如“二、三产业”）。
- **官方案例**：国标示例“只能看到两侧八九公里和前方一二十公里范围内的地面”；人民日报微博《新版标点符号用法》同此。
- **依据**：GB/T 15834-2011 4.5.3.4。

**6. `...` → `……`**
- **为什么错**：中文省略号的形式是**六连点**，不是三个英文句点。`...` 是英文里的省略写法。
- **正确用法**：省略号写作 `……`，占两个字位置；最多连用两个（十二连点）。
- **官方案例**：国标 4.11.2 规定省略号形式统一为六连点。
- **依据**：GB/T 15834-2011 4.11.2、5.1.5。

**7. `说"这个方案我不同意"。` → `说：“这个方案我不同意。”`**
- **为什么错**：三处问题叠加：①引号用了英文直引号；②“说”后面引出的是完整话语，属于提示性词语，应当用**冒号**；③引语独立成句，句末句号应放在**引号之内**，放在外面会让读者以为话还没说完。
- **正确用法**：中文用弯引号；“某某说”引出完整引语用冒号；引文完整独立时，句末点号放引号内。
- **官方案例**：国标 B.1.5 示例“老张说：‘小王去北京了。’”（引文前用冒号）；人民日报海外版《引文末尾句号的位置（杜老师语文信箱）》（2023-06-10）——“独立使用的引语，句末点号放引号之内”。
- **依据**：GB/T 15834-2011 4.8.2、B.1.5、B.2.1。

**8. `--` → `——`**
- **为什么错**：破折号是两个“——”，不是两个英文连字符；且破折号占两个字位置、不能断开。
- **正确用法**：破折号写作 `——`。
- **官方案例**：人民日报海外版《破折号的常见用法（杜老师语文信箱）》（2021-05-29）列举破折号十种用法，形式均为“——”。
- **依据**：GB/T 15834-2011 4.10.2、5.1.4。

**9. `1、` → `1.`**
- **为什么错**：阿拉伯数字作序次语时，后面应加**下脚点**（外文标点），顿号是中文序次语（汉字数字）专用的。
- **正确用法**：序次语后标点按形式分工——汉字数字后用顿号（“一、”），阿拉伯数字后用下脚点（“1.”），加括号的序次语后不用点号（“（1）”）。
- **官方案例**：共产党员网《公文写作中这些标点，你用对了吗？》（2022-03-11）：“第三层‘1’后面要用小圆点‘.’……常见的错误用法有‘1、’”；国标 B.3.3 同此。
- **依据**：GB/T 15834-2011 B.3.3；并与 GB/T 9704-2012 层次序数一致。

#### 三、修正全文

> 这次培训主要有三个目标，一是掌握标点符号的规范用法，二是熟悉公文格式。我们邀请了张老师（中文系副教授）来做分享。他读了《乡土中国》《月亮与六便士》两本书。飞机在 6000 米高空飞行时，只能看到两侧八九公里范围内的地面。他想了很久……然后说：“这个方案我不同意。”这就是答案——唯一正确的答案。1. 请大家先读题。

#### 附：可商榷项

- 第 3 条（并列书名号之间的顿号）属国标允许的弹性用法，保留顿号并不算错，是否删去可由作者定夺。
