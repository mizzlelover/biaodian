# 标点校对 · GB/T 15834-2011 Skill

> **信息安全提醒（请先阅读）**
> 本 Skill 用于检测文本中的标点符号用法，不会替你判断文本是否可以公开。请勿把企业内部、涉密、敏感、受限或明确禁止对外的文稿，上传到未获授权的在线模型、第三方服务或公共仓库。使用前，请按所在单位的信息安全、数据分类分级、保密和授权要求确认；必要时先完成脱敏。若已在本地或企业内网部署大模型，可将本 Skill 部署在内部环境使用，并由使用单位自行落实访问控制、存储、日志、传输和输出文件管理。

把一段中文交给它，它会逐处检查标点符号：**哪里错了、正确的应该是什么、为什么**。错的每一处都给出 GB/T 15834-2011 的条款依据，并附上人民日报、新华社、央视等官方媒体公开讲过的同类案例，让修改不只是"改对了"，还顺带把规则讲明白。

## 为什么需要它

中文标点难，不在于规则多少，而在于**看不出这里有问题**。

"这个人其实不知道。"和"这个人其实不知道？"，差一个标点，意思就反了。一句话里既有顿号又有逗号又有分号时，谁高谁低、谁该管谁，全凭语感。GB/T 15834-2011《标点符号用法》2012 年就实施了，可直到今天，人民日报、新华社还在反复刊发标点用法的科普和纠错——说明这些坑，谁都会踩。

本 Skill 做的事只有一件：把国标拆成**能一条条执行的判定**，再把官媒公开的纠错案例接上去，让"改标点"这件事有据可依、有例可循。

## 项目缘起

我一直在做中文正式材料的工具。做公文排版时，一个绕不开的体会是：格式能靠脚本严丝合缝地对齐国标，标点却不行——它嵌在语义里，靠"看起来差不多"永远过不了关。

标点符号的现行国标是 GB/T 15834-2011（常被误写成"15843"，其实没有这个号）。这份国标把 17 种标点分成点号和标号，还用规范性附录 A 专门讲"不能这样用"。可它毕竟是条文，普通人读起来并不知道自己错在哪。

真正把规则讲活的，是官媒那些公开的科普与纠错：人民日报海外版"杜老师语文信箱"逐问逐答，新华社的中国新闻奖审核报告直接点出标点差错会写坏句子结构，共产党员网把公文里最容易错的标点列成了清单。我把国标解构为判定矩阵，把这些官方案例收进案例库，做成了这个 Skill。

它现在可以安装到 Codex、Claude Code、OpenCode、Trae Code、Kimi、TraeWork、WorkBuddy 和 ZCode。各平台读的是同一份规则。

## 它怎么工作

一次检测分三层，像人校稿一样，从"看得出来"到"想得明白"：

1. **机械扫描**：`scripts/lint_punctuation.mjs` 先跑一遍确定性规则——半角标点混入中文、英文直引号、省略号写成 `...`、破折号写成 `--`、重复标点、问号叹号叠用超三个、引号括号不配对、概数误用顿号、并列书名号之间加顿号、序次语后的标点、数值范围用 `~`……一次性列全，保证不漏。
2. **语义复核**：脚本查不出的问题由模型按判定矩阵逐条过——句末语气配不配点号、顿/逗/分的层次、引号内外的句末点号位置、"说/道"后用冒号还是逗号、破折号与括号的分工、书名号的适用范围。这一层需要"读懂"，正是国标里最容易被忽略的部分。
3. **给依据、给案例**：每处修改都落到条款号；凡是官媒讲过的类型，附上原文案例和出处链接。

## 输出长什么样

固定三段式，缺一不可。下面是一个节选（完整范例见 [`references/report-template.md`](references/report-template.md)）：

**第一段：问题清单——哪里错了、正确的是什么**

| # | 原文 | 问题 | 应改为 | 依据 |
| --- | --- | --- | --- | --- |
| 1 | `八、九公里` | 概数之间不能用顿号 | `八九公里` | 4.5.3.4 |
| 2 | `说"这个方案我不同意"。` | 英文直引号；"说"后缺冒号；句号应在引号内 | `说：“这个方案我不同意。”` | 4.8.2、B.1.5、B.2.1 |

**第二段：为什么错、为什么这样改（附官方案例）**

> **`八、九公里` → `八九公里`**
> 相邻数字连用表示概数时，是一个整体的数量概念，中间不应顿开。
> 官方案例：国标示例"只能看到两侧**八九公里**和前方**一二十公里**范围内的地面"；人民日报微博《新版标点符号用法》同此。
> 依据：GB/T 15834-2011 4.5.3.4。

**第三段：修正全文**——把修改全部落回原文，可直接替换。

```bash

scripts/install.sh --all          # macOS / Linux
# .\scripts\install.ps1 -All      # Windows
```

## 案例来源

案例库只收**可核验的官方公开来源**，引用时均注明媒体、篇名、日期与链接。目前包括：

- **人民日报**微博《新版标点符号用法》；人民日报《逗号、顿号、分号、点号等易混标点符号，如何正确使用？》
- **人民日报海外版**"杜老师语文信箱"专栏（《引文末尾句号的位置》《"某某说"后的点号》《复句中要正确使用标点》《破折号的常见用法》《引文中的括号》等）
- **新华社**／《中国记者》：中国新闻奖审核委员会工作报告（标点差错实例与计错标准）
- **共产党员网**（中共中央组织部党员教育中心）《公文写作中这些标点，你用对了吗?》
- **央视网**：标点缺失导致误读的报道
- **GB/T 15834-2011** 及其附录自带的全部示例

不是所有官媒的所有用法都绝对正确，因此案例库以**国标条文为最终依据**，官媒案例用于说明与讲解；遇到国标表述为"通常/宜/一般"的弹性用法，报告只作"建议"，不判"错误"。

## 边界

- 只处理标点符号这一层，**不改文意、词语、数字与行文风格**；错别字、语法、事实问题不在职责范围。
- GB/T 15834-2011 是**推荐性**国家标准；个别用法存在允许的选择空间，本工具不把"可选"当"错误"。
- 案例库与判定矩阵会持续补充；新增案例必须来自可核验的官方公开来源，无法核验的一律不收录。
